# 프로젝트 계보와 기여 구간

이 문서는 서로 다른 구현을 하나의 완벽한 제품처럼 합치지 않고, 확인된 시간 순서와 한계를 남깁니다.

## 확인된 계보

| 기간 | 구현 | 확인 방법 | 공개 판단 |
| --- | --- | --- | --- |
| 2021-06-29 ~ 2022-03-11 | 초기 인프라·컨테이너 실험 | 공개 저장소의 17개 커밋 | 현재 포트폴리오 공개 기준에 맞게 정리되지 않아 링크하지 않음 |
| 2022-05-25 ~ 2022-08-02 | Go 프로토타입 | 공개 저장소의 78개 커밋 | 현재 포트폴리오 공개 기준에 맞게 정리되지 않아 링크하지 않음 |
| 2022-07-29 ~ 2025-12-02 | 주 Rust 구현 | 비공개 Git 이력과 manifest의 로컬 감사 | 집계 근거만 공개하고 소스·이력은 복사하지 않음 |
| 2023-11-20 ~ 2024-04-10 | 별도 Spring 기반 구현 실험 | 비공개 저장소의 21개 커밋 | Rust 구현과 시간상 겹치는 별도 프로토타입으로 기록 |
| 2026-04-18 ~ 2026-05-05 | React·Axum 중심 현대화 | 비공개 개발 브랜치 감사 | 에이전트 보조 작업이 포함돼 원래 개발 구간과 분리 |

Spring 구현은 Rust 이전 단계가 아니라 Rust 주 구현 도중 진행한 별도 실험입니다. 따라서 이력을 `Go → Spring → Rust`의 단순한 순차 마이그레이션으로 설명하지 않습니다.

## 주 Rust 구현의 활동량

`git rev-list`, 커밋 날짜 집계, manifest 확인을 사용했습니다. merge 여부나 코드 줄 수로 가중하지 않은 단순 커밋·활동일 수치입니다.

| 연도 | 커밋 | 활동일 |
| --- | ---: | ---: |
| 2022 | 103 | 42 |
| 2023 | 1,148 | 118 |
| 2024 | 0 | 0 |
| 2025 | 137 | 41 |
| 합계 | 1,388 | 201 |

가장 오래된 확인 커밋은 2022-07-29, 이 사례집의 본인 개발 근거 종료점은 기본 브랜치의 2025-12-02 스냅샷입니다. 2023-10-18 이후 2025-09-10까지는 주 Rust 저장소에 커밋 공백이 있습니다. “4년 내내 매일 개발했다”는 식으로 부풀리지 않습니다.

모든 커밋의 작성자 필드가 한 계정으로 보이는 것은 참고 자료일 뿐입니다. Git author metadata만으로 실제 단독 저작을 완전히 증명할 수는 없습니다.

## 2026년 변경을 분리한 이유

개발 브랜치에는 2026년 54개 커밋이 3개 활동일에 집중돼 있고, 명시적인 에이전트 공동 작성 커밋이 포함됩니다. 주요 변화에는 다음이 있습니다.

- 역사적 Yew 프런트의 보관과 React 19 전환
- Actix 중심 구성의 Axum 전환 작업
- Timescale 관련 현대화와 구조 정리

따라서 2026년 구간은 “2026-05-05 감사 스냅샷의 실험 상태”로만 다루며 2022~2025년 본인 개발량에 더하지 않습니다. 해당 스냅샷을 근거로 “지금도 Yew/WASM UI를 운영한다”고도 말하지 않습니다.

## 2026-10 공개 사례집 제작

이 공개 저장소의 문서, 합성 SQL, Rust 실행 예제와 검증 자동화는 2026-10에 사용자가 범위와 공개 여부를 결정하고 AI 에이전트가 원본을 읽기 전용 감사하면서 함께 재구성했습니다. 따라서 이 저장소의 새 예제 자체를 2022~2025년에 작성한 원본 코드나 당시의 단독 저작 증거로 제시하지 않습니다. 역사적 경험을 설명하는 근거와 현재의 AI-assisted 공개 작업을 분리합니다.

## 데이터 규모 기록의 한계

비공개 백업 문서에는 2025-09-25 스냅샷의 두 이력 테이블이 각각 11,045,205행과 23,923,126행으로 기록돼 있습니다. 이 사례집은 원시 데이터나 dump를 포함하지 않으며, 이 수치를 현재 운영량·고유 사용자·처리 성능으로 해석하지 않습니다. 당시 저장 데이터 규모를 설명하는 기록값일 뿐입니다.
